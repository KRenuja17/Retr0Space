# OTHERWHERE

A cinematic, browser-based atlas inspired by the five supplied images in `img/`. Each world has its own palette, atmosphere, typography composition, transition, and optional synthesized soundscape.

Requires Node.js 20.11 or later. There are no runtime dependencies.

```sh
npm run dev
npm run check
npm run build
```

Open http://localhost:4173. Use the chapter rail, arrow keys, wheel, or swipe to travel. The atlas shows all five worlds. **Begin drifting** starts a slow automatic journey; pause it at any time. Sound is opt-in. Motion can be paused independently, and the experience respects the operating system's reduced-motion preference. Fonts are hosted locally with their SIL Open Font licenses.

The original image files are preserved. This is a fictional art experience, not a claim of authorship of the reference artwork. Source details and design references are in `DESIGN.md`.
